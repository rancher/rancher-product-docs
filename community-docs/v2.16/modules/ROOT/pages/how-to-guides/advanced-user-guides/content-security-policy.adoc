= Content Security Policy
:description: Configure the Content-Security-Policy header that Rancher serves with the UI
:page-languages: [en, de, es, fr, ja, pt, zh]
:revdate: 2026-10-02

Rancher serves a https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP[Content Security Policy] (CSP) response header with the UI. A CSP tells the browser which content the page is allowed to load and which other pages are allowed to frame it, which limits the impact of cross-site scripting and clickjacking.

The header is sent on every response from the Rancher server, including the UI and the `/v1` and `/v3` APIs.

A few endpoints that serve untrusted third-party content replace it with a stricter policy of their own, `default-src 'none'; style-src 'unsafe-inline'; sandbox`. Chart icon downloads and the `/meta/proxy` endpoint both do this. Changing `ui-csp-policy` has no effect on those responses.

[#_the_default_policy]
== The Default Policy

Rancher sends this policy unless you configure a different one:

[source,text]
----
base-uri 'self'; object-src 'none'; frame-ancestors 'self'
----

`base-uri 'self'`:: Restricts the `<base>` element to the Rancher origin, so an injected `<base>` tag cannot re-point the page's relative URLs at another host.
`object-src 'none'`:: Blocks `<object>`, `<embed>`, and `<applet>` content.
`frame-ancestors 'self'`:: Allows only same-origin pages to frame the Rancher UI.

[#_changing_the_policy]
== Changing the Policy

The policy is stored in the `ui-csp-policy` setting. This setting is not listed on the *Global Settings* page in the UI, so edit the corresponding `Setting.management.cattle.io/v3` custom resource with `kubectl`:

[source,shell]
----
kubectl edit settings.management.cattle.io ui-csp-policy
----

Set the `value` field to the policy you want to serve:

[source,yaml]
----
apiVersion: management.cattle.io/v3
kind: Setting
metadata:
  name: ui-csp-policy
value: "base-uri 'self'; object-src 'none'; frame-ancestors 'none'"
----

Rancher reads the setting on each request, so a change takes effect immediately and does not require a restart.

[IMPORTANT]
====
A policy that is too restrictive can stop the Rancher UI from loading. Because `ui-csp-policy` is not available on the *Global Settings* page, you need `kubectl` access to the local cluster to undo such a change. Test a new policy on a non-production Rancher server before applying it.
====

[#_disabling_the_header]
== Disabling the Header

To stop Rancher sending the header, set the value to `none`:

[source,shell]
----
kubectl patch settings.management.cattle.io ui-csp-policy --type merge -p '{"value":"none"}'
----

A Rancher setting falls back to its default when its value is empty, so clearing `value` restores the default policy rather than removing the header. `none` is the sentinel that turns the header off. It is matched without regard to capitalization or surrounding whitespace, so `None` and `NONE` also work.

Only a bare `none` is treated as the sentinel. A policy that uses `'none'` as a source expression, such as `object-src 'none'`, is served as written.
