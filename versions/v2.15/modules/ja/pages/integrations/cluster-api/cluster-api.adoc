{url-cluster-api-index}[{turtles-product-name}] は、Cluster API (CAPI) と Rancher を統合し、プロビジョニングされた Kubernetes クラスターのライフサイクルを管理する https://kubernetes.io/docs/concepts/extend-kubernetes/operator/#operators-in-kubernetes[Kubernetes Operator] です。Rancher Turtles を使用すると、次のことができます：

* CAPI でプロビジョニングされたクラスターに Rancher Cluster Agent をインストールして、CAPI クラスターを Rancher にインポートできます。
* https://cluster-api-operator.sigs.k8s.io/[CAPI Operator] を {url-cluster-api-capiprovider}[CAPIProvider] リソースで管理します。

{xref-turtles-overview}[Overview] セクションでは、インストールオプション、Rancher Turtles のアーキテクチャ、および簡単なデモについて説明します。詳細については、 {url-cluster-api-index}[{turtles-product-name} ドキュメント] を参照してください。
