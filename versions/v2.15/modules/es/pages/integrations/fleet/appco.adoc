= Deploying applications from the SUSE Application Collection
:page-languages: [en, de, es, fr, ja, pt, zh]
:revdate: 2026-08-13
:page-revdate: {revdate}

Continuous Delivery provides a dedicated deployment flow for the **SUSE Application Collection**, serving as a third option alongside GitRepos and standard HelmOps under **App Bundles**. Built on a specialized HelmOps configuration, this flow allows you to browse, configure, and distribute curated application bundles across downstream clusters natively through the Rancher UI without creating a GitRepo.

[#_prerequisites]
== Prerequisites

* SUSE Rancher Prime v2.15.1 or later.
* An active account on https://apps.rancher.io/[].

[#_authenticating_with_the_suse_application_collection]
== Authenticating with the SUSE Application Collection

Before deploying applications for the first time, you must authenticate SUSE Rancher Prime with your SUSE Application Collection account:

* Log in to https://apps.rancher.io/[].
* Select your user profile/login menu and generate a new **Access Token**.
* Copy the access token for use in the Rancher UI setup.

[NOTE]
====
Credentials are saved automatically upon initial verification. Subsequent visits to the SUSE Application Collection menu will load the application catalog without requiring you to re-enter your credentials.
====

[#_deploying_an_application_bundle]
== Deploying an application bundle

[#_ui_workflow]
=== UI workflow

. In the left navigation bar, select the **Continuous Delivery** icon.
. From the main menu, select **App Bundles**.
. On the App Bundles view, select **SUSE Application Collection**.
. If accessing the tab for the first time, enter your credentials:
.. Enter your **Username**.
.. Enter your **Access Token** acquired from `apps.rancher.io`.
. After your credentials are verified, browse the application catalog and select the Helm chart you wish to install.
. Select the desired chart **Version**.
. Configure the target clusters, target namespaces, and any custom Helm values.
. Click **Create**. Fleet will deploy the selected application bundle to your designated downstream clusters.

[#_secret_management_and_image_pull_handling]
== Secret management and image pull handling

When deploying applications from the SUSE Application Collection to downstream clusters, Fleet automatically handles container image authentication:

* *Automatic `imagePullSecrets` generation:* Fleet provisions and manages the necessary `imagePullSecrets` across target namespaces in downstream clusters.
* *Seamless image pulls:* Workload nodes pull container images directly from the registry without requiring manual credential configuration on downstream clusters.
* *Credential lifecycle:* Any updates to registry authentication details are automatically propagated down to downstream cluster secrets by Fleet.

[WARNING]
.Do not modify SUSE Application Collection charts directly in Rancher
====
Always manage applications deployed via Fleet exclusively through your Fleet App Bundle definitions. Direct modifications to Rancher-managed charts outside of Fleet will *not* be reflected in your Fleet HelmApps, leading to configuration drift and potential synchronization errors.
====
