SUSE Rancher Prime is the enterprise edition of Rancher. It gives platform teams one place to manage Kubernetes clusters, containers and virtual machines, whether they run in the cloud, in your data center or at the edge.

Rancher Prime uses the same open source code as the Rancher project which remains fully open source. You can adopt Prime without being locked in to SUSE or any other vendor. What Prime adds is what you need to run Rancher in production, including a trusted software supply chain, longer support lifecycles and enterprise support from SUSE.

== The SUSE Rancher Prime Difference

=== One control plane for any Kubernetes

Rancher Manager lets you provision, govern and audit every cluster from a single console. It manages SUSE's RKE2 and K3s distributions and Virtual Clusters. It also manages any CNCF-certified distribution, including Amazon EKS, Azure AKS and Google GKE. Access control, security policies and audit logs work the same way across all of your environments, air-gapped sites included. Rancher Manager connects to the identity providers you already use, such as Active Directory, OpenLDAP and Okta.

=== Built for production

Prime installation assets and container images come from a trusted registry that SUSE manages. Images are signed and include SBOMs and provenance data, so your security team can confirm exactly what is running.

RKE2 and K3s receive up to five years of long-term support. This gives you time to plan upgrades on your own schedule.

SUSE Kubernetes experts are available at any moment under defined SLAs. Prime customers also get Kubernetes advisories and reference architectures.

=== Add what you need

The platform grows with your requirements, and everything you add is managed from Rancher Manager. SUSE Virtualization runs virtual machines alongside containers. SUSE Storage provides distributed block storage for your clusters. SUSE Security protects containers from build through runtime. SUSE Observability gives you full-stack visibility and is built on OpenTelemetry. SUSE Application Collection and Developer Access give developers hardened application images and a self-service option to get what they need.

=== Open by design

Rancher Prime doesn't require a specific operating system, storage product or proprietary tooling. You decide which components to use and where they run.
