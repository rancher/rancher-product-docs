{rancher-product-name} serves a https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP[Content Security Policy] (CSP) response header with the UI. A CSP specifies allowed page content and framing sources. This header restricts cross-site scripting (XSS) and clickjacking attacks.

The server includes this header in every response, including the UI and the `/v1` and `/v3` APIs.

Endpoints serving untrusted third-party content override this with a stricter policy: `default-src 'none'; style-src 'unsafe-inline'; sandbox`. Chart icon downloads and the `/meta/proxy` endpoint use this restriction. Updating the `ui-csp-policy` setting does not affect these endpoints.

[#_default_policy]
== Default Policy

Rancher sends the following policy by default:

[,text]
----
base-uri 'self'; object-src 'none'; frame-ancestors 'self'
----

`base-uri 'self'`:: Restricts the `<base>` element to the Rancher origin. This prevents injected `<base>` tags from redirecting relative URLs to an external host.
`object-src 'none'`:: Blocks `<object>`, `<embed>`, and `<applet>` content.
`frame-ancestors 'self'`:: Restricts UI framing to same-origin pages.

[#_change_the_policy]
== Change the Policy

The policy is stored in the `ui-csp-policy` setting. This setting is omitted from the *Global Settings* UI page. Edit the corresponding `Setting.management.cattle.io/v3` custom resource with `kubectl`:

[,shell]
----
kubectl edit settings.management.cattle.io ui-csp-policy
----

Set the `value` field to the desired policy:

[,yaml]
----
apiVersion: management.cattle.io/v3
kind: Setting
metadata:
  name: ui-csp-policy
value: "base-uri 'self'; object-src 'none'; frame-ancestors 'none'"
----

Rancher evaluates this setting on every request. Changes take effect immediately without a system restart.

[IMPORTANT]
====
An overly restrictive policy can break the Rancher UI. Because `ui-csp-policy` is not available on the *Global Settings* page, recovering UI access requires `kubectl` access to the local cluster. Always test custom policies in a non-production environment first.
====

[#_disable_the_header]
== Disable the CSP header

To stop sending the CSP header, set the `value` field to `none`:

[,shell]
----
kubectl patch settings.management.cattle.io ui-csp-policy --type merge -p '{"value":"none"}'
----

Clearing the `value` field restores the default policy instead of removing the header. Setting `value` explicitly to `none` acts as the sentinel to disable the header. The sentinel value is case-insensitive and ignores surrounding whitespace, so `None` and `NONE` function identically.

[NOTE]
====
Only a standalone `none` value disables the header. Standard source expressions using `'none'` (such as `object-src 'none'`) function normally within a policy string.
====
